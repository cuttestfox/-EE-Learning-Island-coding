# -EE-Learning-Island-coding
海大電機・校園學程島是一個給國立臺灣海洋大學電機系大學部（115 學年度入學、一般生）的互動式課程介紹網頁。它把課程表和學程資訊放進一座 Q 版的校園小島，讓新生和學弟妹用逛地圖的方式了解四年怎麼修課。

網站特色

系主任導覽：Q 版系主任譚仕煒會跟著你的滑鼠游標走，一進站就介紹電機系和網站的用途。
校園地圖：點電機一館、二館的 5 間教室（206、209、216、207、214）看必修課，也可以點海事大樓（國文、英文）、人文大樓（博雅）、海洋廳（海洋科學概論）和圖書館。
各年級小人：大一到大四共 24 位同學在島上沿著道路走動。點小人會顯示他的路徑、上課地點和每學期學分。
分組與實驗室：要到大三才分組，所以只有大三、大四有組別，也才能進實驗室。六大領域（通訊與訊號處理、控制、電力、固態電子、電波、資訊科技）各有實驗室，點進去可看組別特色和老師專長。
學期時期：可切換學期初、期中考、期末考、學期末，考試期間大家會湧向圖書館讀書。
課程資訊頁：另有必修科目清單和畢業學分（必修 112、選修 24、畢業 136）。
